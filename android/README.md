# Pichome Android

一个轻量的 Android WebView 客户端，加载现有 Pichome 手机网页：

`https://pichome.lempet.top:5575/`

## 第一版功能

- 独立 APK、应用名称和图标
- 保持网页登录与 Cookie
- 支持网页选择并上传多个文件
- 支持网页视频播放及播放器全屏
- 支持 Android 返回键网页后退
- APK 专属请求自动通过 Caddy 入口认证，不显示账号密码框
- 为手机状态栏、导航栏和屏幕开孔预留系统安全区域，上下系统栏统一使用 `#303135` 深灰背景
- 左侧分类树使用 Element Plus 原生节点点击切换：点击文件夹名称展开直接子文件夹，再次点击收起
- APK 隐藏左右侧栏箭头按钮，支持边缘滑入打开、在侧栏内反向滑动收回，并让侧栏实时跟随手指
- APK 保留顶部时间/电量状态栏，将底部导航栏设为可临时唤出的沉浸式状态，并向系统申请左右整条物理屏幕边缘作为侧栏手势区
- 图片和视频详情使用贴满手机屏幕左右边缘、按素材比例计算高度的居中弹窗，点击外部关闭
- 视频详情打开后自动播放；逐帧滑动区上方提供横向贴满手机屏幕、带当前时间/总时长的视频总进度滑块，可直接拖到任意时间且松手后没有惯性，滑块作为悬浮控件显示而不压缩视频窗口；逐帧滑动区按下即进入逐帧，从按下位置开始每移动 7dp 预览一帧，向右前进、向左后退、按住可反复改变方向，松手会立即丢弃尚未呈现的移动距离，不再继续滚动；正常播放期间使用约 96 帧的低分辨率环形画面缓存，反向滑动优先显示 `presentedFrames` 连续且时间紧邻当前位置的缓存帧，缓存不连续时再精确回退一帧；每次反向目标额外限制在当前位置约一帧范围内，避免旧的开头缓存被误认成上一帧而直接跳回首帧，并过滤 seek 期间提前返回的旧画面回调；视频前 1 秒的逐帧预览直接显示原视频高清帧，避免开头画面被低分辨率缓存放大后模糊；屏幕底部仍提供 144×96px 的后退一帧、前进一帧按钮，短按走一帧，长按以 1× 速度连续前进或反向预览；逐帧状态通过常驻 CSS 隐藏播放器控件，随后轻点视频画面会退出逐帧隐藏状态并恢复播放/暂停、时间和进度条等 UI
- APK 双击素材时只把被点击卡片的 `dpath` 传入详情页并将索引固定为 0，不再预载相邻素材；自动播放仅作用于中央当前视频
- APK 内图片和视频详情页按媒体比例及剩余屏幕高度自适应显示
- 外部域名交给系统浏览器打开
- 不申请存储权限；APK 内隐藏下载按钮并拦截下载请求
- 图片和视频预览使用 App 私有磁盘自动缓存：图片边显示边缓存，视频分段播放时后台补全；打开头像用户菜单并点击“查看缓存”，可查看缓存用量和文件数、清理缓存，并把容量上限设为 512MB/1GB/2GB/4GB/8GB/16GB；默认 4GB、单文件上限 512MB，空间不足时按最久未使用自动清理，不申请外部存储权限

## 构建

```bash
cd /home/wangjiafeng/Pichome
./build-apk.sh
```

调试 APK 输出位置：

`app/build/outputs/apk/debug/app-debug.apk`

## 安装

连接开启 USB 调试的 Android 手机后：

```bash
/home/wangjiafeng/构建apk依赖包/android-sdk/platform-tools/adb install -r app/build/outputs/apk/debug/app-debug.apk
```

当前是调试签名版本，适合直接安装测试。正式长期使用时可以再创建独立签名的 release APK。
