# Pichome Sync 0.5.1

通过 Tailscale 在 Linux 服务器上的 Pichome/Eagle 素材库与其他电脑的 Eagle 之间同步。

## 当前功能

- 手动导入数量不设上限，插件会自动分页处理。
- 自动单向同步：开启后连续导入直到追平 Pichome；追平后每分钟巡检新增素材。
- 自动双向同步：同步两端新增素材、分类移动和删除状态。
- 删除采用可恢复方式：Eagle 使用回收站，Pichome/Eagle 源库只标记删除，不物理删除文件。
- 自动单向与自动双向互斥；开启双向同步前会显示风险确认框。
- 升级后首次双向扫描只建立基线，不执行历史移动或删除。
- 两端同时变化时，操作时间相差超过 10 秒会自动采用较新操作；时间过近才暂停为冲突。
- 明确删除会记录在服务端 `/var/lib/pichome-eagle-sync/sync-state.json`，单纯缺少素材不会被误判为删除。

## 界面

- 主界面只保留“自动单向”“自动双向”“手动同步”三个操作按钮。
- 三个按钮下方分别显示 Pichome 有效素材数与 Eagle 受管文件夹树内的有效素材数。
- 当前模式、总进度、正在同步的素材及单个文件传输进度显示在按钮下方。
- 服务器连接、素材库、手动数量、同步总开关和 Eagle 环境收纳在默认折叠的“更多设置”中。

## 同步范围

- 双向同步只管理插件创建的 `Pichome · 参考库` 文件夹树。
- 分类移动同步适用于已经由 Pichome 镜像到 Eagle 的分类。
- Eagle 中新加入受管文件夹的常见图片和视频会回传到 Pichome。
- 标签、备注、评分和原文件替换暂不做双向覆盖。

## 安装

双击 `Pichome-Sync-0.5.1.eagleplugin`，或将其拖入 Eagle 窗口。插件作为后台服务启动；点击插件图标时会显示设置窗口。

1. 确认两台电脑都连接同一 Tailscale。
2. 点击“测试连接”。
3. 打开同步总开关。
4. 选择自动单向同步或自动双向同步。
5. 首次启用双向后，等待“已建立同步基线”的提示，再测试新的移动或删除。
